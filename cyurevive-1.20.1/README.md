# CyuRevive · 宠物复活

为 Minecraft **Java 版 1.20.1 / Fabric 与 Forge** 制作的宠物复活模组：让宠物像玩家一样拥有出生点，认窝安家、倒地救援、睡醒回窝

## 安装

使用 Java 17。对应加载器的 `mods` 文件夹放入：

**Fabric**

| 文件 | 版本 |
| --- | --- |
| `cyurevive-1.20.1-fabric-1.0.jar` | 本模组 |
| Fabric API | `0.92.12+1.20.1` 或兼容的更新版本 |

**Forge**

| 文件 | 版本 |
| --- | --- |
| `cyurevive-1.20.1-forge-1.0.jar` | 本模组 |
| Forge | `47.4.10` 或兼容的更新版本 |

Forge 端不需要任何附属模组；Fabric 端需自行安装 Fabric API

可在 [Releases](https://github.com/HansOffice/cyurevive/releases) 页面下载对应加载器的 Jar 文件放入 `mods` 目录：
- 单人游戏：安装在客户端即可
- 多人游戏：服务器与参与玩家的客户端均需安装

## 使用

| 操作 | 效果 |
| --- | --- |
| 手持认家牌右键自己的宠物 | 选中这只宠物，显示后续操作；再次点它取消选择 |
| 拿认家牌右键宠物窝 | 第一次预览住所，再点同一个窝确认认家并归位；点别的窝可以更换 |
| 拿认家牌潜行右键空气 | 取消选宠或住所预览 |
| 空手右键宠物窝 | 查看这个窝的住户：谁在住、谁在等回家、谁正在赶来 |
| 潜行空手右键宠物窝 | 召回属于自己的待回家宠物；没有等待的则让自己的活宠物立即回到独立住位 |
| 潜行右键自己的宠物 | 查看它的家在哪里 |
| 喂食倒地的宠物 | 喂它这个物种爱吃的东西救回来：狗吃肉骨头、猫吃生鱼、鹦鹉吃种子、马类吃干草块（含配置的救回物品） |
| 挖掉宠物窝 | 移除设施并通知住户主人；保留宠物记录，无窝时复活到主人身边 |

认家牌可用两块木板、两根线和一根骨头合成，不会因认家而消耗。选择或预览超过一分钟、离线或宠物离开当前维度后，需要重新选中；失败时保留原来的家，不会改绑其他宠物

创造模式中，认家牌与五种设施集中在「CyuRevive · 宠物复活」独立标签页，不再出现在原版功能方块分类；搜索页仍可检索

宠物栏占地 3×3，马棚占地 3×4、高四格，狗狗窝占地 1×1，猫咪窝与鹦鹉栖架占地 1×1；入口朝向随放置方向变化，宠物栏与小窝放置需三格净空，马棚需四格净空和完整坚实地面，不能覆盖方块、液体或附近实体

每只宠物有独立住位，猫狗不会叠在同一个窝里，大型伙伴也不会挤在一个栏位里：

| 窝 | 只接待 | 合成 |
|---|---|---|
| 宠物栏 | 一只体型合适的宠物，包含马、驴、骡与羊驼 | 四根云杉栅栏加一块干草块加三块云杉木板 |
| 马棚 | 一只马、驴或骡 | 三块云杉木板、两根去皮云杉原木、两根云杉栅栏和一块干草块 |
| 狗狗窝 | 一只狼 | 四块羊毛加一根骨头加三块木板 |
| 猫咪窝 | 一只猫 | 四块羊毛加一条生鳕鱼加三块木板 |
| 鹦鹉栖架 | 最多两只鹦鹉，各有独立栖位 | 四块羊毛加一根羽毛加两根木棍 |

确认认家、搬家或窝边集合时，活宠物在安全住位一次归位，到位后猫狗与鹦鹉保持坐姿；夜间自动回家先走到入口再落位。休息时会间歇抬头观察，马类偶尔低头啃食，不额外消耗物品或恢复生命。骑乘、牵引、受伤、主动取消坐下或拆除设施会退出休息，路过设施不会触发归家

物种不对、体型过大或落点被挡住时不会入住；住位数量是物理上限，`bed-capacity` 只能进一步限制数量，不能把单栏位变成多宠物栏

命名是选填，不影响选宠、认家与回窝。看着自己放置的设施执行 `/cyurevive home <名称>`，可让多个设施归入同名的家；名字会显示在住户信息与宠物列表中，不会按相邻距离自动合并，也不会跨玩家共享操作

潜行召回只操作当前设施里属于自己的宠物，不会把整院子的伙伴一起叫回来

## 指令

| 指令 | 效果 | 权限 |
| --- | --- | --- |
| `/cyurevive` 或 `/cyurevive help` | 查看常用操作，条目可点击回填 | 全体玩家 |
| `/cyurevive help admin` | 查看当前场景的管理帮助 | 管理员 |
| `/cyurevive home <名称>` | 看着自己放置的设施，指定家的名称，最多 32 个字符 | 全体玩家 |
| `/cyurevive list` | 查看自己的宠物、家位置与状态（带编号） | 全体玩家 |
| `/cyurevive unbind <序号>` | 移除自己某只宠物的家，按 list 编号 | 全体玩家 |
| `/cyurevive recall` | 把待回家的宠物远程召回到身边 | 全体玩家 |
| `/cyurevive list <玩家>` | 查看指定玩家的宠物 | OP（权限等级 2） |
| `/cyurevive unbind <玩家> <序号>` | 移除指定玩家某只宠物的家 | OP（权限等级 2） |
| `/cyurevive revive [玩家]` | 安排自己或指定在线玩家的待回家宠物复活 | OP（权限等级 2） |
| `/cyurevive forbid <玩家>` | 收回指定玩家的宠物复活资格 | OP（权限等级 2） |
| `/cyurevive unforbid <玩家>` | 恢复指定玩家的宠物复活资格 | OP（权限等级 2） |
| `/cyurevive purge [玩家]` | 清空自己或指定玩家的待复活宠物，不可恢复 | OP（权限等级 2） |
| `/cyurevive status` | 查看宠物数据概况 | OP（权限等级 2） |
| `/cyurevive doctor [fix]` | 体检宠物数据，加 fix 自动修复安全项 | OP（权限等级 2） |
| `/cyurevive reload` | 热重载 `config/cyurevive.toml` | OP（权限等级 2） |

常用帮助只显示自己的养宠操作，有管理权限时可用 `/cyurevive help admin` 查看管理帮助。单人管理帮助突出自己的宠物与世界维护，开放局域网后按多人场景展示；控制台直接显示指定玩家管理与维护指令

管理权限沿用原版规则，单人模式不会自动开放管理操作。`revive` 与 `purge` 省略玩家时操作自己，控制台必须填写玩家；目标只允许一名玩家，不能用匹配多人的选择器批量操作。`purge` 清空记录，以及解绑待复活宠物，都会删除对应的等待记录，无法恢复

远程召回由 `command-recall` 配置开关控制，消耗与窝边召回共用 `recall-item`

收回复活资格会同时清空该玩家的待复活宠物并阻止其认窝；`/cyurevive doctor` 可体检全服宠物数据并自动修复安全项；为宠物更换新住所时直接认新窝即可自动搬家

## 宠物离世之后

- 受致命伤时宠物不会立刻死去，而是倒地进入 60 秒濒死倒计时：停留原地、发出求救声并冒烟，最后十秒求救声会变急，喂对东西即可救回并附带短暂恢复
- 倒地提醒包含救援物品、坐标和所在维度；救援进入最后十秒时会再提醒主人一次，喂错物品不会消耗
- 主人六格内看着倒地宠物时，物品栏上方显示剩余救援时间；到期后不能靠喂食延长救援
- 只有认过家的宠物离世后才会等待复活；尚未认家的宠物仍可现场救援，但超时后按普通死亡处理
- 救不回来才真正离世，离世后名字、毛色、项圈与该版本已有的装备全部保留，窝上飘起一缕烟，进入待回家状态
- 有待回家宠物的窝会散发淡淡的灵魂微光，路过一眼就能看出有宝贝在等
- 主人睡一觉、等到冷却结束（默认 3 分钟）、到窝边潜行空手右键或用 `/cyurevive recall`，都能让它回来；回来时先在落点凝聚灵光再现身，并发出它自己物种的叫声
- 宠物窝被拆后宠物记录仍然保留，无窝时复活到主人身边；重新在同位置放好完整设施即可恢复住位
- 落点被方块、液体或其他实体挡住时会继续等待，清理空间后重试，不会把宠物塞进墙里
- 手动召回先检查可回家的宠物与物品数量，数量不足不会扣物；已接受的召回遇到落点变化会继续等待，不重复收费
- 列表与窝边住户信息显示自动回家冷却、归来准备时间和目标；区域未加载、安全落点受阻或数据异常时显示对应原因
- 复活后的保护抵挡普通伤害，按游戏时间到期；卸载与重启不会重新给予完整时长，虚空伤害与 `/kill` 不受这项保护限制
- 成功登记复活记录的宠物不产生普通死亡战利品或经验，装备与箱内物品随宠物归来；未认家、被取消资格等正常死亡仍按原版处理
- 离线时宠物不会偷偷复活，回服后会收到提醒

## 配置

配置文件位于 `config/cyurevive.toml`，注释使用 `#`，改完用 `/cyurevive reload` 热重载或重启生效

无效配置会阻止模组初始化；重载失败时保留当前设置，具体原因会写入控制台

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `bind-radius` | 12 | 确认认家时，选中的宠物与主人的最大距离 |
| `bed-capacity` | 1 | 每个设施的数量上限；栏、马棚、猫窝、狗窝最多 1 只，栖架最多 2 只 |
| `max-pets-per-player` | 8 | 每人绑定上限，-1 不限 |
| `revive-on-sleep` | true | 睡觉复活通道 |
| `revive-cooldown-seconds` | 180 | 自动回窝冷却，0 关闭 |
| `recall-enabled` | true | 窝边手动召回开关 |
| `command-recall` | true | `/cyurevive recall` 远程召回开关 |
| `recall-item` / `recall-item-count` | 空 / 1 | 手动召回的消耗物品与数量，空为免费 |
| `downed-enabled` / `downed-seconds` | true / 60 | 濒死倒地开关与倒计时 |
| `downed-items` | 骨头 | 可救回濒死宠物的物品列表 |
| `downed-heal-percent` | 0.5 | 救回后恢复的血量比例 |
| `respawn-health-percent` | 1.0 | 复活后的血量比例 |
| `respawn-protection-seconds` | 5 | 抵挡普通伤害的游戏秒数，0 关闭；不阻止虚空与 /kill |
| `broadcast-death-message` | false | 死亡消息是否全服广播 |
| `bed-private` | false | 窝私有化：开启后只有放置者能让宠物入住 |
| `night-return` | true | 夜晚主人不在时，窝边宠物自己走回窝睡觉 |
| `revive-ceremony` | true | 召回的宠物先凝聚灵光再现身 |
| `bed-aura` | true | 有待回家宠物的窝散发灵魂微光 |
| `rescue-regen-seconds` | 5 | 濒死救回后的生命恢复时长 |
| `revivable-types` | 狼/猫/鹦鹉/马/驴/骡/羊驼/商队羊驼 | 可绑定的宠物类型，填实体 ID，可自行增删 |

其它模组里认主的宠物同样支持：对于沿用原版认主、死亡与存档机制的动物，把它的实体 ID 加进 `revivable-types`，且体型符合住位空间，就能认家、倒地救援与复活，名字、装备与随身物品照常保留

## 常见问题

**右键窝没有认家**：先拿认家牌右键自己的宠物，再点窝预览并确认；普通工具与食物不再自动寻找附近宠物。手持方块会照常放置，空手右键查看住户

**活宠物不回窝**：到它的窝边潜行空手右键集合；检查设施是否完整、住位是否被挡住，宠物是否被骑乘或牵引、是否倒地或正处于受伤状态。集合只作用于当前维度内已加载的活宠物，夜间自动回家还要求主人不在该维度

**待复活宠物不回窝**：检查主人是否在线、设施是否完整、落点是否被挡住；远方未加载的窝会等待，不会强行加载，也可用远程召回回到主人身边

**濒死宠物喂东西没救回来**：喂它本物种能吃的食物或配置里的救回物品，主手和副手都可使用；喂错不会消耗，超过救援时限就不能再救回

**拆了窝宠物会丢吗**：不会。宠物记录与复活资格保留，没有可用的窝时会寻找主人身边的安全位置

**马身上的鞍和箱子里的东西会丢吗**：不会。离世时鞍具、马甲、箱子与箱内物品都记在快照里，复活时原样带回

## 构建

```bash
./gradlew :fabric:build
./gradlew :forge:build
```

构建产物输出在 `fabric/build/libs/` 与 `forge/build/libs/` 目录下。Gradle 使用 JDK 21，通过工具链自动获取 JDK 17，生成 Java 17 字节码
